# 04 · 控制环路与 PID 整定

> 车"能走"和"走得稳"是两回事。这篇讲：全车有哪几个环、每个环的输入输出是什么单位、
> 初始参数怎么来的、上车后按什么顺序调。

---

## 1. 三种工作模式

| 模式 | 左拨杆 | 平移 (vx, vy) | 旋转 w | 典型现象 |
|---|---|---|---|---|
| 分离 | 上 | 左摇杆（云台系） | **拨轮直接给** | 车沿枪口方向平移，车头保持不动 |
| 跟随 | 中 | 左摇杆 | **闭环：让车头对准枪口** | 转云台，车头跟着转 |
| 小陀螺 | 下 | 左摇杆（云台系） | **恒定非零自旋** | 车边转边走，方向不变 |

### 1.1 摇杆映射

```
 左摇杆                     右摇杆                    拨轮
   ↑ 前进                     ↑ 枪口抬高                分离：底盘自转
 ← + → 左移/右移              ← + → 云台左右转           小陀螺：自转快慢
```

- `vx = rc_lv × 2.0 m/s`
- `vy = −rc_lh × 2.0 m/s`（**注意负号**：摇杆右推为正，但车体 +y 是左）
- `yaw_rate = −rc_rh × 6 rad/s`（**注意负号**：右推 → 顺时针 → yaw 减小）
- `pitch` 目标按 `rc_rv × 2 rad/s` 积分，并限制在 [−0.9, +0.7] rad

### 1.2 跟随模式的控制律

```
δ = 云台朝向 − 车头朝向          （来自 G2C 的 yaw_joint）
w = Kp · δ − Kd · ω_陀螺仪       （ω 是底盘角速度，用来阻尼）
w 限幅到 ±6 rad/s
```

为什么加 `−Kd·ω`：只用一个 P 去追角度，车会转过头再追回来（像倒车入库打方向打多了）。
用陀螺仪直接测出"已经在转多快"，提前减小指令，就是**阻尼**。

`Kp = 4` 时，误差 0.5 rad → 目标转速 2 rad/s，大约 0.25 秒追上。

### 1.3 小陀螺的 w

```cpp
magnitude = 1.5 + |拨轮| × (6.0 − 1.5)     // 最小 1.5 rad/s，保证"非零旋转分量"
direction = (拨轮 < −0.05) ? −1 : +1
w = direction × magnitude
```

拨轮回中时仍然以 1.5 rad/s 自旋——这是小陀螺模式的定义，不是 bug。
想停下来就把左拨杆拨出小陀螺档。

## 2. 全车一共有几个环

| 环 | 数量 | 输入（误差） | 输出 | 周期 | 代码 |
|---|---|---|---|---|---|
| 舵角环 | 4 | rad | GM6020 电压（±25000 raw） | 1ms | `chassis.cpp` |
| 轮速环 | 4 | rad/s | M3508 电流（±8 A） | 1ms | `chassis.cpp` |
| 云台 yaw 环 | 1 | rad（世界角） | 达妙力矩（±3.5 N·m） | 1ms | `gimbal.cpp` |
| 云台 pitch 环 | 1 | rad（关节角） | 达妙力矩 | 1ms | `gimbal.cpp` |
| 跟随环 | 1 | rad（δ） | 底盘 w（rad/s） | 1ms | `robot.cpp` |

> **调参第一原则：先搞清楚这个环的输入输出单位。**
> 同样是"Kp = 100"，输入是 rad 和输入是 rad/s，效果差几个数量级。

## 3. PID 类是怎么实现的

位置式：

```
输出 = Kp·e + Ki·∫e dt + Kd·de/dt
```

代码在 `RobotComponents/component/pid.hpp`，有三个工程细节：

### 3.1 积分限幅 + 抗饱和

```
integral += e·dt
integral 夹到 ±i_lim          ← 积分本身不会无限大
out = Kp·e + Ki·integral + Kd·d
if (输出已饱和 && e 还在往同方向推) 撤销本次积分   ← 条件积分
```

**不这么做的后果**：舵机顶住机械限位时，误差一直存在，积分越积越大；
等舵机离开限位，要花很久才能把积分"放完"，表现为"反应迟钝一大截"。

### 3.2 微分低通

1ms 周期下，反馈的量化噪声会被微分放大成剧烈抖动（`Δe/0.001` = 放大大约 1000 倍）。
所以微分项过一阶低通：

```
d_filtered += α·(d_raw − d_filtered)
```

`α` 越小越平滑、滞后越大。舵角环用 0.08，云台环用 0.1。

### 3.3 首帧不做微分

`first_run_` 标志：第一次调用时没有"上一帧误差"，直接差分会产生一个巨大的假尖峰。
`reset(measure)` 的参数只为兼容旧调用保留，不参与计算；抑制首帧差分的是 `first_run_`。

## 4. 初始参数是怎么定的

> 这些是待台架整定的初值；限幅可约束指令，不能替代电流、温升、机械行程和稳定性实测。

### 4.1 舵角环（误差 rad → 电压 raw）

| 参数 | 值 | 依据 |
|---|---|---|
| Kp | 10000 | 误差 0.1 rad（5.7°）→ 1000 raw ≈ 4% 电压，能推动轮子但不猛 |
| Ki | 2000 | 抵消舵机负载带来的稳态误差 |
| Kd | 150 | 抑制大角度回摆（加分项） |
| 输出限幅 | 20000 | GM6020 满量程 25000，留 20% 余量 |
| 积分状态限幅 | 1 rad·s | `Ki × integral` 最多贡献 2000 raw；API 限制的是状态，不是输出 |

当前 GM6020 使用电压指令。是否稳定取决于负载与增益，须测阶跃、超调和温升。

### 4.2 轮速环（误差 rad/s → 电流 A）

| 参数 | 值 | 依据 |
|---|---|---|
| Kp | 0.35 | 误差 20 rad/s（R=0.066m 时约 1.3 m/s）→ 7 A，接近限幅 |
| Ki | 1.5 | 消除摩擦/负载造成的稳态误差 |
| Kd | 0 | 速度环不需要微分（反馈本身就抖） |
| 输出限幅 | 8 A | 与电机电流限幅一致 |

### 4.3 云台环（误差 rad → 力矩 N·m）

| 参数 | yaw | pitch | 依据 |
|---|---|---|---|
| Kp | 2.5 | 3.0 | 误差 0.2 rad → 0.5~0.6 N·m，能克服摩擦/重力 |
| Ki | 0.6 | 1.0 | pitch 需要更大积分来"顶住重力" |
| Kd | 0.12 | 0.15 | 阻尼 |
| 输出限幅 | 3.5 | 3.5 | 达妙满量程 7.5，给一半 |

## 5. 为什么云台用"纯力矩 + 自写 PID"，不用达妙内置位置环

达妙 MIT 协议支持 `pos_des, vel_des, kp, kd, torq`，内置位置环可以省掉我们自己的 PID。
我们仍然选择 **kp = kd = 0，只用 torq 通道**，理由：

| 方案 | 优点 | 缺点 |
|---|---|---|
| 用内置位置环 | 参数少、电机内部环带宽高 | 控制律在电机里，整定/观察都不方便；换电机型号要重来；yaw 需要的是"世界角"，内置环只能做关节角 |
| **纯力矩 + 自写 PID** | 整定逻辑全在代码里、可单测、yaw/pitch 可以跑不同控制律 | 参数更保守，带宽受限于力矩环 |

关键还是 yaw：它要跟踪的是**世界角**，而内置位置环只能跟踪关节角，物理上就不适用。
pitch 其实两种都行，为了代码统一（一个 `Gimbal` 类、一个 PID 类），也走力矩。

## 6. 整定步骤（照着做）

> 原则：**从内到外、从单件到整车**。里面的环没稳，外面怎么调都是白调。

### 第 0 步：准备

- 车架空（轮子离地），电池充满；
- 遥控器先开并保持右拨杆急停，待两板 IMU 标定、全部电机和双板链路就绪；按 docs/06 确认 Working 后再解除急停；
- 手边准备随时拨急停。

### 第 1 步：舵角环（单轮）

正常固件静止时保持舵角，不能靠手掰后自动回零来测试。通电出力时禁止手接触机构。
在整车架空、全部安全条件满足后，用小幅遥控前进/横移指令产生转向阶跃，记录
最终方向 `desired_angle`、限速目标 `angle`、实测角和电压输出；未对准最终方向时驱动轮输入应为零。
孤立单轮闭环需要另行实现合规台架入口，当前固件不提供绕过状态机的测试通道。

### 第 2 步：轮速环（单轮，仍架空）

1. 推前进 20% 摇杆，看四个轮子转速是否一致、有没有"一顿一顿"；
2. 一顿一顿 → Kp 太大或 Ki 太大；起步肉 → Kp/Ki 加大；
3. 落地后在低速（10%）再试一次：低速最容易暴露静摩擦问题。

### 第 3 步：云台 pitch

1. 用右摇杆上下拨，看枪口跟不跟手、松手后会不会慢慢往下掉；
2. 往下掉 → Ki 加大（或加一点点重力前馈，本工程预留了接口）；
3. 上下抖 → Kp 太大 / Kd 太小。

### 第 4 步：云台 yaw

1. 快速左右拨右摇杆，看枪口是否"甩"；
2. 用手快速转车体，枪口应该**纹丝不动**（世界系稳定生效）；
3. 如果枪口跟着车体转 → 检查 IMU 是否真的装在云台上、`yaw()` 是否随枪口变化。

### 第 5 步：跟随环

1. 跟随模式，静止；
2. 用手把云台转到偏离车头 30°，松手；
3. 车应该平稳转过来对准，**不来回摆**：
   - 摆 → Kd 加大（0.15 → 0.3）；
   - 太慢 → Kp 加大（4 → 6）。

### 第 6 步：整车联调

- 低速画 8 字，看有没有"拖胎"；
- 小陀螺 + 平移，看平移方向是否稳定；
- 急停反复按，看是否每次都干净利落。

## 7. 现象 → 原因 → 调法

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 轮子原地高频抖动 | 舵角环 Kp 过大 | Kp 减半，或加大 Kd |
| 舵轮回摆时"哐"一下 | 没做等效解翻转 / 速率限幅太小 | 查 `chassis_ik_solver.cpp` |
| 起步明显画弧 | 舵角没到位就驱动 | 确认门控使用最终等效角；必要时减小 `kSteerReadyAngle` 并重新测量。加大阈值会更早放行 |
| 车走直线但慢慢偏 | 四个舵角零点不齐 / 轮速环积分不一致 | 重新标定零点 |
| 推杆没反应，过一会儿突然动 | 积分饱和 | 检查 `i_lim`，确认 `reset()` 被调用 |
| 松杆后车还往前溜 | 加减速限幅 + 惯性 | 正常现象；可加大 `kLinearAccel` 让减速更快 |
| 云台松手后慢慢下垂 | pitch 积分不够 | 加大 `kPitchPidKi` / `i_lim` |
| 云台跟着车体转 | yaw 用了关节角而不是世界角 | 查 `gimbal.cpp` 的 `yaw_world_meas` |
| 跟随模式车一直转圈 | δ 符号反了 | 查 `robot.cpp` 的 `w = Kp·δ` 符号 |
| 小陀螺时平移方向漂 | δ 没有每周期更新 | 查 `chassis_->setMotion(ramped_, delta())` |
| 急停后恢复时"抽"一下 | 没做无扰切换 | 查 `initWorkingTargets()` / 使能上升沿 |
