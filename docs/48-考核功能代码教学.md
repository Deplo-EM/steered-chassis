## 第 0 站：工程地图

```
Chassis/            底盘板：4×M3508 驱动 + 4×GM6020 转向
  Task/             main_task（1 kHz 主循环）、comm_task（收发 + 喂狗）
  RobotModules/     robot.cpp（模式/状态机/安全）
                    chassis.cpp（双环控制）
                    chassis_ik_solver.cpp（逆解）
Gimbal/             云台板：Yaw/Pitch 两个达妙 DM 电机（MIT 力矩模式）
  Task/             main_task、comm_task
  RobotModules/     robot.cpp（状态机/授权/目标）
                    gimbal.cpp（yaw/pitch 闭环）
RobotComponents/    公共库：电机驱动、PID、IMU、遥控解码、双板协议、CAN 监督
tests/              主机回归（把上述源码拉到电脑上编译运行）
```

数据流：

```
遥控器 → 云台板 UART3 解码 → 塞进 GimbalData → CAN → 底盘板
底盘板：IMU/电机反馈 → 状态机 → 三模式 → 逆解 → 双环 → 8 个电机
底盘板：ChassisData（yaw 速率、pitch 目标）→ CAN → 云台板 → 两轴闭环
```

> 记住一句话：**遥控接收机在云台板上**，底盘用的摇杆值是云台转发过来的。

## 第 1 站：主循环与 update 五步

### 1.1 上电初始化（`Chassis/Task/component/main_task.cpp:64`）

顺序不能乱：

| 步 | 做什么 | 为什么在这个位置 |
|---|---|---|
| 0 | 读 IWDG 复位标志并清标志 | 判断上次是不是看门狗复位 |
| 0.5 | 故障注入归零、保存构建标签 | 保证符号留在固件里，可离线核对 |
| 1 | 构造 8 个电机（ID/方向/减速比） | 底盘 init 需要电机指针 |
| 2 | IMU 只做芯片配置 | 零漂标定要 1 ms 周期慢慢做 |
| 3 | 电机/PID/逆解器接进底盘 | 底盘模块依赖它们 |
| 4 | 遥控/IMU/底盘/通信接进 Robot | Robot 是总调度 |
| 5 | 最后启动通信任务 | 它一启动就收帧 + 喂狗 |

### 1.2 每 1 ms 的 `MainTask()`（`main_task.cpp:128`）

```cpp
if (robot::FaultActive(kHangControlLoop)) { while (true) {} }  // 审计用
robot->update();
```

那个死循环是**故意**的：喂狗在通信任务里，控制任务卡死后 200 ms 内看门狗必然复位，
证明喂狗没有藏在控制循环里。

### 1.3 `Robot::update()` 五步（`robot.cpp:139`）

```cpp
imu_->update();          // 1. 传感器（标定期间也要读）
updateInput();           // 2. 遥控
updateStateMachine();    // 3. Dead/Resurrection/Working
applyOutput();           // 4. 生成并下发（急停最外层）
updateCommData();        // 5. 写通信帧
```

**为什么急停放最外层**：如果只在 Working 分支里判急停，“自检阶段舵角回中”在按着急停
上电时仍会动。放最外层保证急停一按，任何状态都一步不动。

## 第 2 站：逆解（`chassis_ik_solver.cpp` 的 `solve()`）

### 2.1 输入输出

```cpp
solve(motion /*云台系 vx,vy,w*/, delta /*云台-车头*/, steer_now[4], dt, out[4],
      keep_rotation /*小陀螺档*/);
```

输出每轮：`speed`（有符号线速度 m/s）、`angle`（限速后舵角，连续角）、
`desired_angle`（未限速等效角）。

### 2.2 第 1 步：云台系 → 车体系

```cpp
vx_c = vx*cosδ - vy*sinδ;
vy_c = vx*sinδ + vy*cosδ;
```

δ=+90°（枪口在车头左边）推前进 → 车体系 (0,+1) → 车往左平移，即**沿枪口方向走**。
考核说明 3.2 印的 R(−δ) 与它自己的 δ 定义冲突，代码按物理用 R(+δ)，并用单测锁定。

### 2.3 第 2 步：单轮速度 = 平移 + 旋转

```cpp
v_ix = vx_c - w * y_i;   // v = v_平移 + ω × r
v_iy = vy_c + w * x_i;
```

`ω × r` 展开 = (−w·y, +w·x)。

### 2.4 第 3 步：速度 → 舵角 + 轮速

```cpp
magnitude = hypot(v_ix, v_iy);  // 轮子该转多快（m/s）
angle     = atan2(v_iy, v_ix);  // 舵轮该朝哪（rad）
```

`magnitude` 永远为正，方向单独用 `sign` 表示。

### 2.5 第 4 步：等效解与限速

- 舵轮“转 180° + 轮子反转”是同一个滚动方向，叫**等效解**；
- `branch_` 记住上次选支，±90° 边界附近用 `steer_flip_margin_` 做回差，避免来回翻；
- 伺服目标从 `last_angle_` 起步，每拍最多走 `max_steer_rate_ * dt`；
- 禁入区（`steer_keepout`）：直取/反向两支都穿不过时，该轮标记 blocked，整组归零。

### 2.6 第 5 步：小陀螺保旋转

```cpp
if (keep_rotation) {
  w = Clamp(w, -max_wheel_speed/module_radius, +...);
  if (平移 + |w|·半径 > 轮速上限) {
    // 先保旋转，平移按剩余轮速等比缩放
  }
}
```

这就是“慢速小陀螺 + 平移时旋转消失”的修复。

## 第 3 站：三模式（`robot.cpp` 的 `generateCommand()`）

### 3.1 平移（三档共用）

```cpp
raw.vx = -UnitClamp(lv) * kMaxLinearSpeed;   // 负号 = 实车 180° 标定
raw.vy =  UnitClamp(lh) * kMaxLinearSpeed;
```

`UnitClamp` 先夹 ±1：解码出错给 ±3 也不会三倍速。

### 3.2 分离档

```cpp
raw.w = UnitClamp(wheel) * kMaxChassisW;
```

拨轮直接给自转速度，底盘不追云台。

### 3.3 跟随档

```cpp
float w = kFollowKp * delta + kFollowKd * gyroZ();  // 注意是 +
if (|delta|<0.02 && |gyro|<0.05) w = 0;             // 对正死区
raw.w = Clamp(w, -8, 8);
```

| 细节 | 实车原因 |
|---|---|
| `+ Kd*gyro` | 减号时是正反馈，Kd 越大越跑飞 |
| 小死区 | 编码器量化/陀螺零偏会让车在“对正”附近拽舵 |
| 上限 8 | 切换瞬间 δ 大，不限幅会猛冲过头 |

### 3.4 小陀螺档

```cpp
magnitude = kMinSpinW + |wheel|*(kMaxSpinW-kMinSpinW);
direction = (wheel < -0.05f) ? -1 : +1;
raw.w = direction * magnitude;
```

拨轮只调大小；回中时用 `kMinSpinW` 保证“永远有非零旋转”。

### 3.5 斜坡

```cpp
ramped_.w = Slew(ramped_.w, raw.w, kAngularAccel * kDt);
```

每拍最多变多少，保护机械。

## 第 4 站：底盘双环（`chassis.cpp` 的 `update()`）

顺序：**读反馈 → 逆解 → 对齐判定 → 轮速环 → 舵角环 → 堵转/禁入区 → 下发**。

### 4.1 读反馈

```cpp
steer_feedback_[i] = steers_[i]->angle();
steer_velocity_[i] = steers_[i]->vel();
steer_current_[i]  = steers_[i]->curr();
wheel_velocity_[i] = wheels_[i]->vel();
```

任何非有限值都会让 `feedback_healthy_` 变 false，整组停车。

### 4.2 轮速环

```cpp
omega_target = cmd[i].speed / radius * cos(drive_error[i]);
current[i] = wheel_pids_[i]->update(omega_target, wheel_velocity_[i], dt);
```

- 除以半径：线速度 m/s → 角速度 rad/s；
- `cos(舵角误差)`：轮子没完全对准时只出有效方向的分力，减少侧向拖胎。

### 4.3 舵角环

```cpp
steer_request_raw[i] = steer_pids_[i]->updateWithMeasuredRate(steer_err, rate, dt);
```

**D 用实测转速，不用目标变化率**：目标一跳 D 就猛给，舵机会“啪”地甩。

### 4.4 对齐门与前馈

- 对齐门：四轮误差都小于阈值才给驱动（`drive_ready_`）；
- 现场版 `ROBOT_ACCEPT_STUCK_STEER` 绕开对齐门并关闭堵转锁存；
- 前馈：`|误差|>0.15` 且滤波后转速 `<0.6` 时补 0.70 A，帮它越过静摩擦。

## 第 5 站：云台（`gimbal.cpp` + 云台 `robot.cpp`）

### 5.1 yaw：世界系

```cpp
yaw_err = WrapPi(yaw_target_world - imu->yaw());
yaw_input = yaw_pid->updateWithFeedforward(yaw_err, world_rate, dt, ff, limit);
```

- 反馈用 **IMU 世界 yaw**：车体转动不影响云台指向；
- `WrapPi` 折到 ±π，避免绕 2π 走远路；
- 前馈 = 底盘下发的 `yaw_rate`，直接补力矩。

### 5.2 pitch：关节系

```cpp
pitch_err = pitch_target - pitchJoint();
pitch_input = pitch_pid->updateWithFeedforward(pitch_err, joint_rate, dt, ff, limit);
```

- 用**关节编码器**：炮管相对车体的俯仰就是关节角；
- 重力前馈 `1.4*cos(pitch)` 直接补住重力，不靠积分慢慢攒；
- 世界水平补偿（云台 `robot.cpp`）：

```cpp
setPitchTarget(command.pitch_target - imu_->pitch());
```

### 5.3 力矩限幅

PID 的输出限幅（yaw 4.5 / pitch 5.0 N·m）外面还套着**电机自己的上限 3.5 N·m**
（`ins_motor.cpp` 的 `kYawTorqueLimit/kPitchTorqueLimit`）。所以“再硬也硬不过 3.5”。

### 5.4 云台状态机

`all_ok = 通信 && IMU && 电机 && 未意外失能 && 未超时 && CAN 正常`；
不满足 → Dead；正常 → Resurrection → Working。

## 第 6 站：安全

| 机制 | 位置 | 作用 |
|---|---|---|
| 状态机 | 两板 `robot.cpp` | 条件不满足就撤权 |
| 急停 | `applyOutput` 最外层 | 本地/对板急停，一步不动 |
| 看门狗 | `comm_task.cpp` | 控制任务卡死 200 ms 内复位 |
| CAN 监督 | `can_tx_guard.hpp` | 发送失败/邮箱满不静默丢帧 |

看门狗：

```cpp
should_feed = kDebugAlwaysFeedWatchdog ||
    (controller->canFeedWatchdog() && RemoteAliveForWatchdog());
if (should_feed) IWDG_Refresh();
```

**不是“活着就喂”，是“系统健康才喂”。**

## 第 7 站：双板通信

文件：`RobotComponents/component/gimbal_chassis_comm.hpp`。

帧：**8 字节 + CRC8**（多项式 0x07，初值 0），第 7 字节是校验。

| 结构体 | 方向 | 关键字段 |
|---|---|---|
| `ChassisData` | 底盘→云台 | `yaw_rate`（云台该转多快）、`pitch_target`（关节目标）、急停/状态 |
| `GimbalData` | 云台→底盘 | `yaw_joint`（δ）、`pitch_joint`、**转发的遥控数据** |

`decode()` 校验 CRC、字段范围、序号；任何一项不过**整帧丢弃**，不刷新在线时间，
并累计 `rx_error_count_`。

## 名词表

| 名词 | 全称/含义 | 在本项目哪里用 |
|---|---|---|
| IMU | 惯性测量单元，测角速度/加速度 | 云台世界 yaw、底盘跟随阻尼、pitch 水平补偿 |
| 逆解 | 由车体速度反推每个轮子的舵角+轮速 | `chassis_ik_solver.cpp` |
| 等效解 | 舵角转 180° + 轮子反转 = 同一滚动方向 | 逆解第 4 步 |
| MIT 模式 | 达妙电机的力矩/位置混合输入模式 | 云台 `ins_motor.cpp` |
| 前馈 | 不等误差出现，先按已知扰动量补一份输出 | 云台 yaw 速率、pitch 重力、舵向摩擦 |
| 看门狗 | 定时器，超时未“喂”就复位 | `comm_task.cpp` |
| CRC | 循环冗余校验，检测帧是否损坏 | 双板通信 |
| 死区 | 输入很小的时候当作 0，避免抖 | 摇杆、跟随对正 |
