# 四轮低速下地候选

**当前状态：已实现首跑控制；实车放行尚未完成。** 右后舵的固定卡点、四组舵/驱 ID 配对、独立断动力与真实停机都需要台架记录。此前出现过 Yaw 命令异常且遥控急停未能制止。此版单独编译云台失能，保留原考核三模式构建。

| 产物 | ELF 内标签 | 用途 |
|---|---|---|
| [锁定底盘](../Chassis/build/ground-trial-locked/steered_chassis_ground_locked.elf) | `GROUND-TRIAL-LOCKED` | 核对通信、反馈和停机路径。遥控操作不能产生舵或轮电流。 |
| [失能云台](../Gimbal/build/ground-trial-disarmed/steered_gimbal_ground_disarmed.elf) | `GROUND-GIMBAL-DISARMED` | 保留 UART3 遥控转发；Yaw、Pitch 只接收失能指令。 |
| [有动力编译复核产物](../Chassis/build/ground-trial-motion-review/steered_chassis_ground_motion.elf) | `GROUND-TRIAL-MOTION` | 预备首跑，待放行项完成后才进入实车流程。与失能云台成对使用。 |

两个底盘变体都要求收到配套云台的双轴正常失能反馈状态。普通云台不发这个标志。标志基于驱动回报及在线检测，只说明当前获取到了失能反馈。独立断动力单独核验；控制板暂停、掉电或总线断开后，不依赖软件继续发送停机帧。

## 动作和停机

- 首跑只支持左拨杆上档、车身前后直行。移动用左纵杆，车头定义前向；没有横移、跟随、小陀螺和云台控制。启动车轮前允许四个舵低电流转到目标，四个舵均到位后才给轮速目标。
- 车身速度指令最大 0.20 m/s，正常起停按 0.35 m/s² 变化；每个驱动请求电流绝对值最多 2.0 A，电流版舵电机仍为 1.2 A。这里列的是**软件指令上限**，带载车速、稳定性和停车距离均待实测。
- 轮组放行要求实测舵角和限速目标距最终方向都不超过 0.10 rad；驱动中超过 0.15 rad 整组撤销轮输出。持续等不到四轮对齐达 600 ms，四舵、四轮归零并锁存。原堵转判据保留，翻转仍启用。前馈、探针、排除轮、逐轮放行、禁止翻转和关闭堵转等设置不能与首跑构建混用。
- 有动力变体的授权顺序：两板完成自检且车已停稳 → 左拨杆上、右拨杆下确认急停 → 保持左右摇杆和拨轮回中，将右拨杆拨中 → 回中连续 250 ms 后，新的左纵杆指令超过阈值才起步。松杆或直接反打时先把指令降到零，再经回中确认后才能起步。切档、右杆有输入、右拨杆到上或急停、云台失能确认丢失，均撤销授权。异常解除后要重新走下档确认和回中。

## 去现场之前

按 [38 号放行清单](38-四轮版下地放行清单.md) 的顺序闭环。动力隔离后检查右后舵干涉；依组内要求在稳固台架、车轮离地时分别确认每个 GM6020、M3508 对应哪一个物理轮位、方向和零点。数组仍为候选 `{3,4,1,2}`，舵角零点按物理轮位排列。已有证据与缺项见 [39 号复核](39-舵向前馈停机与轮位复核.md)。用实际驱动停机和独立断动力的结果验收急停，不依赖调试器、看门狗提示或 CAN 入队状态。场地与停车距离核实后，才安排带动力直行；异常停机应保留同一次记录。

Ozone 查看对应 ELF 的符号：`g_ground_build_tag` 区分构建，`s_robot → peer_input_ → ground_disarmed` 看配套云台状态，`s_robot → ground_gate_ → phase_` 看起步阶段。若软件因舵向停机，`s_chassis → last_steer_stall_ → alignment_timeout_mask` 留下对齐超时轮位；四位次序为左前、左后、右后、右前。`g_chassis_dbg.drive_ready` 只表示四轮驱动对齐门，`Working` 只表示状态机完成自检。
