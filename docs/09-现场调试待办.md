## 0. 上车前必须准备（代码侧）

- [ ] **加"测试模式"入口（约 10 行）**

      **为什么必须加**：`Robot::applyOutput()` 每 1ms 都会调用 `chassis_->stop()`
      （只要没进 Working 或者急停生效），而 `stop()` 会把 8 个电机的输入全部写 0。
      所以在调试器里手动 `setInput(2.0f)`，**下一毫秒就被清零**，
      CAN 上发出去的仍然是 0——单电机测试根本做不了。

      **做法（二选一，等有硬件再定）**：
      - A. 运行时开关：全局 `volatile bool g_test_mode` + `volatile float g_test_input[8]`，
        `applyOutput()` 开头判断：若 `g_test_mode` 为真，则直接下发 `g_test_input`，
        跳过状态机（**急停判断必须保留在最前面**）。
      - B. 编译期开关：`#define TEST_MODE 1`，`applyOutput()` 里走测试分支。

      **要求**：默认关闭；打开时急停仍然有效；测完必须改回。

- [ ] **确认减速比**：说明书 2.3 写 19.2（出厂）；若实车换过齿轮箱，改 `ins_motor.cpp`
- [ ] **确认轮半径与轮组坐标**：说明书 6.2 → `0.066` / `±0.167`（已预置）
- [ ] **确认 pitch 软件限位**：当前 `-0.9 / +0.7 rad` 是经验值，需实测机械行程

## 1. 单电机（轮子架空）

- [ ] 轮电机 0：给 +2A → 应朝**车头**滚；`vel()` 读数为正
- [ ] 舵电机 0：给 +3000 raw → 应**俯视逆时针**转
