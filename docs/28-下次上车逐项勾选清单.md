# 下次上车逐项勾选清单：分离档松杆与三档复验

本轮首先回答两件事：转动云台时，分离档松左杆后底盘能否平顺停下；如果再进 `Dead`，是哪条保护触发。本页可以独自完成有条件的架空检查和 Ozone 取证。**台架条件不够，就做到安全的那一步为止；架空通过不等于可以直接落地。**

## 1. 准备与烧录：这次只换底盘

- [ ] 固定车架，四个轮胎完全离地，云台和舵轮的活动范围不碰手、线缆或支架；确认能直接切断电机动力。隔离电机动力再烧录，待烧底盘控制板仍须按正常方式供电。不会独立隔离动力时，先不进行带动力操作。使用原有 J-Link、接线和遥控器，不改电机设置。
- [ ] 遥控器先开，**右拨杆下档急停、左拨杆上档分离，两个摇杆和拨轮全回中**。J-Link 接底盘板，不把两块板原有的板间连接拆开。换探针或线时先按现场电源流程断电。
- [ ] Ozone 若连着旧会话，保持急停、动力隔离后执行 `Stop Debug Session`，再打开 [chassis_separate_release.jdebug](../debug/ozone/chassis_separate_release.jdebug)。文件应指向 `Chassis/build/separate-release/steered_chassis_steer_current_field.elf`。本轮不需要重新编译，不重烧云台。
- [ ] 选择 `Debug → Start Debug Session → Download & Reset Program`（菜单名称可能显示 `Start Debugging`）。核对控制板型号 `STM32F407IG`，下载和校验成功；若日志报告 `Skipped` 且明确说明内容已匹配，可以继续。看到下载或校验失败就停。`Program & Verify` 表示写入后校验，只证明烧录，不证明整车就绪。打开工程或选择 `Attach` 都不等于烧录。
- [ ] 工程已设 `Reset & Run`。看到窗口底部 `CPU running` 后，**不需要按 Stop**，保留会话看实时数据。若确实停在 `Halted`，保持动力隔离和急停、清除多余断点，再用 `Continue`。试车中不点击 `Halt`、不单步、不用 `Stop Debug Session` 当急停。[SEGGER Ozone 用户手册](https://www.segger.com/downloads/jlink/UM08025_Ozone.pdf)

## 2. 启动与就绪

- [ ] 恢复正常的整车连接和动力供电，四轮继续架空。保持右下急停，车与云台静止，等待两板完成标定与自检。先看底盘 Ozone 的 `uwTick` 持续增长，再看 `s_robot → state_ = kWorking`、`estop_ = 1`。`Working + 急停` 是正常的，轮子此时不应主动运动。动力隔离时电机没有在线反馈，停在 `Dead` 可能是预期；动力和反馈都恢复后才评价就绪。
- [ ] Watch 若没有数值：先确认状态栏是 `Connected` 和 `CPU running`，再对变量启用低频实时刷新（例如 5 Hz）。连接已拔掉时没有实时读数，不把旧值当现场值。
- [ ] 状态仍不能进 `Working`：保持急停。先区分 `uwTick` 持续增加还是反复归零；持续增长再看 `s_robot` 的 `peer_online_`、`motors_online_`、`remote_armed_` 和最新 `last_dead_`。计时反复从小值开始时看 `g_reset_by_iwdg`，别一直 Reset 或靠解除急停碰运气。首次启动就没进过 `Working/Resurrection` 时，`last_dead_.causes=0` 可能正常。

## 3. 架空：先分离档，再查偶发停机

全程从小幅、短时开始。右拨杆只用「下档急停／中档试动」；有突然加速、连续摆动、撞擦或异常声音，立即回下档，仍主动出力时切断动力。先停机再看屏幕。

| 勾选 | 左拨杆、动作 | 正常结果 |
|---|---|---|
| [ ] | **上档分离**，拨轮居中；右拨杆移中。两摇杆回中，先只轻拨右摇杆左右、然后回中。 | 云台转。底盘未给平移或自转时，轮胎不应主动持续滚，舵轮不应持续追云台；小幅保持修正不算追随。 |
| [ ] | 右摇杆回中，左摇杆轻推前、左，各做一次；每次松手等停稳。 | 先改变舵轮方向再放开驱动。前、左都按云台坐标系；看舵角和轮胎滚动方向的组合，舵角反向而轮胎也反转可能是等效解。 |
| [ ] | **本轮必测**：右摇杆小幅保持水平转云台，拨轮不动；左摇杆轻推左、松手停稳，再轻推前、松手。先慢做一轮，全过再试一次「松手后还没停稳就换方向」。 | 带左杆时行驶方向可随云台变。松手后剩余平移沿原方向减速，停稳后只转云台不带动底盘；重新推杆时不应突然甩向另一边。底盘保持 `Working`。 |
| [ ] | 小幅动作中用**右拨杆下档**结束。 | 电机不再主动出力，轮胎可因惯性短时转动；不能继续加速或持续顶住。 |

**分离档为什么会转舵：** 补全版考核说明第 6 页 §3.1 取消车身自动跟随；§3.2 仍要求平移以云台朝向为前。架空看的是轮组执行的方向，不能据此证明落地车身一定不会偏转。方向稳定后若仍有明显过冲，按 [Yaw、Pitch、舵向响应对照](26-架空过冲与俯仰响应复测.md) 比较目标与反馈；本轮先不在线改 PID。

## 4. 再进 `Dead`：只记一条，不反复复现

1. **右拨杆回下档，摇杆回中。** 若输出确已停，留着 Ozone 会话和控制板供电，不按 Reset、不重新烧录、不按 Halt。若急停后仍主动出力，优先切动力，记录可以丢，不能带险读数。
2. 在 `Watched Data` 展开 `s_robot → last_dead_`，抄 **`causes`（十进制）、`tick_ms`、`left_centered`**。附上当时哪一档、右摇杆是否还在转云台、`uwTick` 是持续增长还是反复回零。快照是上次进入 `Dead` 时留下的，故障恢复时不会清除；切勿把之前事件当成新事件。
3. `causes=1` 再抄 `steer_stall_sequence` 和 `s_chassis → last_steer_stall_ → stall_mask`；`causes=2` 再抄 `can_failed_cycles`。其他值见 [停机原因表](27-分离档松杆与停机记录.md)。`causes=0` 且 `uwTick` 反复回零时，补抄 `g_reset_by_iwdg`；复位会清掉 RAM 里的停机快照。`g_reset_by_iwdg=1` 说明最近启动记录到看门狗复位，不能单凭它认定故障源。
4. 出现新的 `Dead` 就暂不做跟随、小陀螺或落地验证。停机原因未确认时保留保护、电流限幅和电机配置。若新固件出现明显回归，取证后可在动力隔离与急停下重烧上一份使用正常的**底盘电流固件**：之前用的是 [底盘轴调版](../debug/ozone/chassis_axis_tune.jdebug) 就退轴调版；之前用的是 [首次跑通的电流版](../debug/ozone/chassis_steer_current_field.jdebug) 就退那版。两种情况都不动云台。

可直接复制记录：

```text
底盘已烧 separate-release：是 / 否
分离，只转云台（底盘停稳）：正常 / 异常
分离，左移或前进后松杆：正常 / 异常
分离，没停稳又换方向：正常 / 异常 / 未试
发生 Dead 时的操作：
last_dead_.causes =     tick_ms =     left_centered =
uwTick：持续增加 / 反复归零 / 没看到
causes=1 时：steer_stall_sequence =     stall_mask =
causes=2 时：can_failed_cycles =
发生复位时：g_reset_by_iwdg =
```

## 5. 分离通过后，再架空复验跟随与小陀螺

切档统一按：**右下急停 → 摇杆和拨轮回中 → 选左拨杆档位 → 解除急停短试 → 右下急停**。

- [ ] **中档跟随**：右摇杆给一点偏航后回中，观察轮组是否输出让车头趋向云台的组合，然后急停。车架固定时车头无法真正转过去，不在台架追求夹角归零。确认没有意外 `Dead` 或持续大幅来回摆。
- [ ] **下档小陀螺**：拨轮回中，短暂解除急停，轮组应形成绕底盘中心旋转的组合，马上拨回右下。小陀螺回中仍有自旋目标；停转靠退出模式或急停，**切模式时先急停**。不打满拨轮，不连续空转。台架不稳或线缆会干涉就记「未做」。
- [ ] **云台两轴**：在分离档且左杆回中，小幅试 Yaw、Pitch，记录回摆与追角是否可接受。Pitch 松手保持给定角，不会自动回水平；还没确认机械行程时不试撞端点。不带着疑似卡滞继续加力。

## 6. 台架安全复验通过后，才做受控落地与验收

- [ ] 档位与车头方向确认，舵向零点、滚动方向、俯仰软限位与机械余量有现场记录；急停可及时撤销输出，独立断驱动力手段有效。没有落实场地、机械和停机条件时，不自己进入落地阶段。
- [ ] 用 [台架故障验收清单](08-台架故障注入清单.md) 在有条件的受控环境检查遥控失联、双板失联、看门狗复位与恢复授权，以及台架要求的其他项目。**本轮独自做基础复测时，不在通电试车过程中拔线、制造故障、改喂狗或以断点代替故障验收。** 看门狗复位、命令归零与实际停转分别记录。
- [ ] 具备受控落地条件后，按**低速分离 → 跟随 → 小陀螺**验证。分离应沿云台指向平移而不自动转车头；跟随应让车头靠近云台朝向；小陀螺应持续自旋且小幅平移仍有效。带电脑 SWD 线只做固定台架读数，落地前按断电流程处理外接线缆。验证完均回急停。
- [ ] 汇总三档、两轴、急停、失联和 IWDG 实测结果，保留实际烧录的两份 ELF、对应源码版本及结果。按 [交付与验收对照](00-交付说明与验收对照.md) 检查尚未完成或需要考核方确认的条目，再进行代码与实车验收；不把 1801 项主机回归当作实车验收。裁判、视觉、发射、灯效与可选加分项不影响本轮排查顺序。
