# 06 · 调车手册

> 从"代码编译通过"到"能演示"，中间隔着一整套标定和分步验证。
> 这篇按**依赖顺序**排好了，照着做，每一步都有明确的"通过标准"。

---

## 0. 准备工作

| 项目 | 确认内容 |
|---|---|
| 工具 | ST-Link / Ozone / CubeProgrammer；万用表；螺丝刀 |
| 遥控器 | DT7 已配对、电池有电；**先开机再给车上电** |
| 车体 | 轮子架空（木块/箱子垫起）；电池满电 |
| 接线 | 两板 CAN1 互连；M3508 在底盘 CAN1；GM6020 在底盘 CAN2；达妙在云台 CAN2 |
| 代码 | 两板都烧最新固件；`kWatchdogFeedEnable = true` |

> ⚠️ 接线假设（本工程默认）：
> - 底盘板 CAN1 = 4×M3508 + 双板通信；CAN2 = 4×GM6020
> - 云台板 CAN1 = 双板通信；CAN2 = 2×达妙
>
> 如果实车不是这么接，改两个地方：`comm_task.cpp` 里 `CAN_Send_Msg(&hcan1/hcan2, ...)` 的通道，
> 以及 `CanFilter_Init` 的两路（滤波器是全收的，一般不用改）。
> 接收是**按 ID 分发**的，不依赖通道，所以收这一侧不用改。

## 1. 第 1 步：只上电，不上电机

**做法**：拔掉所有电机信号线（只留两板 + 遥控器 + CAN 互连），上电。

**通过标准**：

- 遥控器开着 → 两板能稳定运行（不反复复位）；
- 调试器里 `GetRobot()->lifeState()` 最终 = **2 (Working)**；
  如果卡在 0，看下面这张表。

| 卡在哪 | 查什么 |
|---|---|
| `lifeState` 一直 0 | `isRemoteOnline()` 是否为 false → 遥控器/串口 |
| | `GetImu()->isCalibrated()` 是否为 false → 等 2 秒；一直 false 看 `errorState()` |
| | `areAllMotorsOnline()` → 这步没接电机，**必然是 false，属正常** |
| | 云台板卡 0 而底盘没好 → 检查 CAN 互连、两板 ID 是否 0x210/0x211 |
| `errorState()` ≠ 0 | IMU 片选接反 → 对调 `ins_imu.cpp` 里的 acc/gyro CS |

> 这一步没接电机，所以**两板都会卡在 Dead**——这是对的。
> 这一步真正要验证的是：**IMU 标定能完成、遥控器能收到、两板能互相看见**。

---

## 2. 第 2 步：电机方向与舵角零点标定

> 这是唯一"必须动手试"的一步，也是后面所有控制的基础。

### 2.1 轮电机（M3508）方向

1. 只接一个轮电机，架空；
2. 用调试器手动调用 `GetMotorWheel(0)->setInput(2.0f)`（2A）；
3. 看轮子转向：**应该是"车前进"的方向**；
4. 反了 → 把 `ins_motor.cpp` 里 `kWheelDir[0]` 改成 `kDirRev`，重烧，再试；
5. 对 4 个轮子逐个做，填满 `kWheelDir[0..3]`。

### 2.2 舵电机（GM6020）方向

1. 手动 `GetMotorSteer(0)->setInput(3000.0f)`（3000 raw 电压）；
2. 看轮组转向：**俯视逆时针**为"正"；
3. 反了 → `kSteerDir[0] = kDirRev`；
4. 逐个确认。

### 2.3 舵角零点

1. 用手把某个轮组摆正（轮面与车头平行，轮子朝前）；
2. 读 `GetMotorSteer(0)->angle()`，记下数值 `a`；
3. 把 `kSteerAngleOffset[0]` 设成 `a`（这样 `angle()` 就变成 0）；
4. 四个轮子逐个做。

> 如果嫌麻烦，也可以只在程序里把四个轮子都命令到 0°，看哪个不是朝前，单独修它的 offset。

**通过标准**：四个轮子都朝前时，`GetMotorSteer(i)->angle()` 都接近 0；
给正电压时四个都逆时针转。

## 3. 第 3 步：单轮闭环

1. 接好一个轮电机 + 一个舵电机；
2. 上电，等 Working；
3. 分离模式，推前进 20%：
   - 舵角应该先转到 0°，然后轮子开始转；
   - 松开后轮子停、舵角保持。
4. 反方向推、横推，观察舵角是否能正确转过去。

**通过标准**：舵角平稳、不抖、不撞限位；轮速跟手。

---

## 4. 第 4 步：整车底盘（分离模式）

1. 八个底盘电机全接上，车架空；
2. 分离模式：
   | 操作 | 期望 |
   |---|---|
   | 推前进 | 四轮朝前同向转 |
   | 推后退 | 四轮朝前反向转 |
   | 推左 | 四轮朝左（+90°）同向转 |
   | 拨轮 | 车原地自旋（四轮成切线姿态） |
3. 落地（低速 10%），确认能走直线、能横移。

**通过标准**：四个轮子方向一致、没有"打架"（轮子互相较劲会听到摩擦声）。

---

## 5. 第 5 步：云台

1. 接上两个达妙，确认上位机已配置（ID / Master ID / PMAX / VMAX / TMAX / MIT 模式）；
2. 上电，观察：
   - 电机是否自动使能（`GetMotorYaw()->is_enabled()`）；
   - 用手转枪口，是否感觉有阻力（力矩环在工作）。
3. 拨右摇杆：
   | 操作 | 期望 |
   |---|---|
   | 右摇杆左右 | 枪口左右转，**松手后停住不漂** |
   | 右摇杆上下 | 枪口俯仰，到软件限位停住 |
4. **世界稳定测试**：快速用手转车体，枪口应该**保持指向不变**（这是 yaw 环最关键的验收点）。

**通过标准**：松手不漂、转动车体枪口不动、pitch 到限位不堵转（听不到"顶住"的嗡嗡声）。

---

## 6. 第 6 步：双板联调

| 模式 | 操作 | 期望 |
|---|---|---|
| 分离 | 转云台 | 车不动，云台独立转 |
| 跟随 | 静止，用手把云台转偏 30° | 车头平稳转过来对准枪口 |
| 跟随 | 边走边转云台 | 车头跟着转，**行进方向始终是枪口方向** |
| 小陀螺 | 左拨杆打下 | 车持续自旋；推杆时**平移方向不随车体旋转而改变** |

**通过标准**：跟随不来回摆；小陀螺时推前进，车会沿着"枪口方向"走而不是画圈。

## 7. 第 7 步：安全项验证（硬性验收）

按顺序做，每一项都要记录现象：

| # | 操作 | 通过标准 | 不通过怎么查 |
|---|---|---|---|
| 1 | 右拨杆打到最下 | 所有电机立刻停（1ms 内） | `readEstopSwitch()` 的值对不对 |
| 2 | 关遥控器 | 约 0.2s 后两板复位，车停 | 喂狗位置是否真的在 DBUS 回调里 |
| 3 | 把 `kWatchdogFeedEnable` 改 false 重烧，再关遥控器 | **不复位**（反证第 2 条是看门狗起的作用） | — |
| 4 | 拔两板之间的 CAN 线 | 0.1s 内两板都停 | `isOffline()` 阈值、`gimbal_enable` 逻辑 |
| 5 | 拔一个电机信号线 | 状态机回 Dead，车停 | `areAllMotorsOnline()` |

> 第 3 条是考核资料明确要求的「看门狗杀死程序一定要进行验证」的做法：
> 用"关掉喂狗"反证"喂狗确实在生效"，而不是嘴上说实现了。

## 8. 验收演示脚本

```
1. 上电（遥控器先开）           → 2.5s 后进入 Working，舵轮回中
2. 分离模式：前后左右各走一下     → 四轮方向正确
3. 跟随模式：转云台 → 车头跟着转  → 对准
4. 跟随模式：手转车体             → 枪口指向不变（世界稳定）
5. 小陀螺：推前进 + 自旋          → 沿枪口方向平移，不画圈
6. 急停                           → 立刻停
7. 关遥控器                       → 0.2s 复位
8. 拔 CAN 线                      → 0.1s 两板停
```

## 9. 故障排查速查表

| 现象 | 先查这个 | 再查这个 |
|---|---|---|
| 上电后板子反复复位 | 遥控器开了吗 | `kWatchdogFeedEnable` 是否误改 |
| 一直不进 Working | `lifeState()` + 四个条件逐个看 | IMU `errorState()` |
| 电机全不动 | `gimbal_enable`（底盘）/ C2G 是否在来 | `state_` 是否 Working |
| 只有一个电机不动 | 该电机反馈 ID 是否命中（`GetRxId`） | 电调灯 / 信号线 |
| 舵角乱摆 | 零点是否标定 | 舵角速率限幅是否生效 |
| 云台慢慢漂走 | 零漂标定期间是否静止 | `kImuCalibMotionThres` |
| 车走不直 | 四轮方向 / 零点 | 轮速环 Ki |
| 跟随一直转圈 | `δ` 符号 | `w = Kp·δ` 的符号 |
| 小陀螺平移画圈 | δ 是否每周期更新 | `chassis_ik_solver.cpp` 旋转符号 |
| CAN 偶发丢帧 | 总线负载（约 70%） | 把双板帧降到 500Hz |
