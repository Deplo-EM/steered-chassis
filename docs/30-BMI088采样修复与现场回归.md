# BMI088 采样修复与现场回归

分离、跟随两档之前均有 `last_dead_.causes=8`，证明底盘 IMU 失去了控制资格。最近的截图中 `last_dead_.imu.reason=kNone`、其他字段为默认值，但没拍到 `causes`，不能判定这次究竟为何停机。旧版只有一份停机快照，后续其他类型的停机可覆盖前一次 IMU 记录。主机测试复现了覆盖；新版另存 `s_robot → last_imu_dead_`，非 IMU 停机不会覆盖它。两份记录仍在 RAM 中，复位后清除。

旧驱动先读 `ACC_STATUS`，即使未就绪也会读加速度数据。[Bosch BMI088 数据手册 §5.3.3](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmi088-ds001.pdf#page=26) 规定：读取任一个加速度数据寄存器会清除就绪位。若新样本在读状态和读数据之间到达，软件可能没把它计为新样本，也无法在下一次轮询发现它。主机用实际驱动和寄存器模型在 20 ms 新鲜度边界复现了误过期。另一个用例复现了新加速度已坏、陀螺 FIFO 为空时没有及时判废。

两板驱动现在只在就绪时读新加速度；姿态解算可在原 20 ms 时限内使用最后一组已校验值。新加速度即使没有配对陀螺也会单独校验，判废时立即停用，等新的合格样本。诊断中的 `has_values=1` 表示有候选数值；若坏加速度没有同拍陀螺帧，`gyro_radps` 显示 NaN，意为“没有该拍读数”。保持原加速度和陀螺仪量级边界、急停、看门狗、重新授权条件和 PID。此次只修改 BMI088 实现文件与允许扩展的 IMU 封装，不修改 BMI088 公共签名和 CubeMX 生成区。这能解决上述两个可复现的缺陷，现场 23 次累计数值拒绝的成因仍待对应样本确认。

现场只换底盘：[chassis_imu_sample_fix.jdebug](../debug/ozone/chassis_imu_sample_fix.jdebug) → `Chassis/build/imu-sample-fix/steered_chassis_steer_current_field.elf`。仍是 `0x1FE` 舵向电流版，云台不用重烧。烧录时保持右下急停和电机动力隔离，按原流程 **Download & Reset Program**，核对下载校验。运行后可结束调试；Ozone 无需一直开着。

在固定架空台架上先小幅验证左上分离，再验证左中跟随；如果再次进 `Dead`，回右下急停后先停止测试。需要读取时，用同一份 ELF **Attach**，不复位，先看 `s_robot → last_dead_ → causes`。若含 `8`，或怀疑之前有过 IMU 停机，再看 `s_robot → last_imu_dead_ → imu → reason` 和对应 `tick_ms`。看见 `kAccLow` 或 `kAccHigh` 再读 `last_rejected.accel_mps2` 的三个值。先看原因再决定是否需要其它数据。

## 2026-11-15 实车回归：新鲜样本的加速度模长偏低

`imu-sample-fix` 的 Ozone 截图显示，分离档在 `98 017 ms` 进入 `Dead`，`last_dead_.causes=8`，遥控来源为云台转发；截图中 `estop_=0`。独立 IMU 快照的 `last_rejected.tick_ms` 同为 `98 017 ms`，`reason=kAccLow`、`calibrated=1`、`healthy=1`、`sample_valid=0`。时钟、加速度、陀螺仪的数据年龄均为 0 ms，上一帧可用控制样本年龄为 1 ms。

被拒绝的三轴加速度为约 `(-0.44473, +0.59716, -0.20174) m/s²`，模长 `0.7714 m/s²`，低于固件的 `2.0 m/s²` 安全门槛。用现版底盘 BMI088 驱动和寄存器模型重放由这三个值反算的原始计数 `(-496, 666, -225)`，得到同样的判废原因，且该样本没有进入姿态解算（13 项检查全部通过）。这验证了停机链路，不能判定之前所有停机原因相同。

现场反馈：架空时有明显晃动或碰到支架；右下急停、车体静止后，`s_imu.rej_sample_` 在观察期间没有继续增加。优先排除台架不稳、轮组与支架干涉。现有记录不能确定晃动与停机的先后，也不能区分振动造成的真实瞬时低读数与运动时偶发的采集异常。现有阈值、重新授权和急停保持原样。

- 停试并隔离电机动力后，检查支架是否稳固、车体是否有相对滑动，四轮和舵轮在活动范围内是否避开支架。无法保证这些条件时，不继续通电试动。
- 台架安全后用同一固件复测：急停下静置确认计数未增，再按[现场计划](31-现场调试与考核收尾计划.md)从分离档一次小幅单方向输入开始。再次明显晃动、碰擦或停机即停止。
- 如静止时也新增数值判废，或稳定台架上仍出现 `kAccLow`，保存新事件的 `tick_ms`、三轴读数和现场工况，下一轮查底盘加速度原始读数和相邻帧。底盘问题仍未结案；[本轮顺序](31-现场调试与考核收尾计划.md)先做空载云台 PID，完整底盘回归留在云台整定后、整车落地和最终验收前。
