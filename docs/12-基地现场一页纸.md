## 二、到基地的顺序（**不要跳步**）

| 步 | 做什么 | 通过标准 | 卡住看哪 |
|---|---|---|---|
| **0** | 只上电，**不接电机** | 约 2.5s 后两板进 Working，互相看得见 | 遥控器开没开 / 接收机接线 / 两板 CAN |
| **1** | 接**一个**轮组（1 舵 + 1 驱），架空 | 推杆：轮子朝车头滚；舵角 0 时轮子朝前 | 方向反 → 改 `kSteerDir` / `kWheelDir` |
| **2** | 四个轮组接齐，架空，最低速 | 四个都朝前；推横移四个都转 90° | 某台方向反 / 零点差 → 单独改那台 |
| **3** | 落地，最低速 | 前进不跑偏、横移不斜、自转不打滑 | 走不直 → 四轮零点 / 轮速环 |
| **4** | 云台 pitch | 摇杆抬高低头，到限位停住不掉 | 一上电顶死 → pitch 方向反 |
| **5** | 云台 yaw | 用手转车体，枪口方向**不动** | 枪口跟着转 → yaw 没用 IMU |
| **6** | 三模式 | 分离：车头不转、平移沿枪口；跟随：车头追枪口；小陀螺：边转边走 | 见下表现象表 |
| **7** | 安全三件套 | 急停立刻停；关遥控器 0.2s 复位；拔 CAN 0.1s 两板都停 | 见下表现象表 |

> 每步之间可以先断电再接线，别带电插电机线。

## 三、现象 → 先看哪

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
| 不进 Working | ①遥控没收到 ②IMU 没标定好 ③有电机离线 ④对板没进 Working | 逐个排除；IMU 要静止 2 秒 |
| 电机完全不转 | CAN 没接 / ID 不对 / 没进 Working | 看 `lifeState()`、`areAllMotorsOnline()` |
| 某个轮子方向反 | `dir` 与实车不符 | 改该台 `kWheelDir` / `kSteerDir` 重烧 |
| 舵角歪一个固定角 | 零点偏移不对 | 把实测角加到该台 `kSteerAngleOffset` |
| 云台不跟手 | IMU 未就绪 / `gimbal_enable` 为假 | 看 `isCalibrated()`、底盘是否 Working |
| **车突然全停、推杆没反应** | **CAN 发送失败被锁存** | **打一下急停再松开**，等 2 秒重新进 Working |
| 一块板重启后车不动 | 安全设计：对板重启会撤销授权 | 同样打一下急停再松开 |
| 起步斜着窜 | 舵角没到位就驱动 | 正常现象；调 `kSteerReadyAngle` 或降低起步速度 |
| 关遥控器不复位 | 看门狗/喂狗被改过 | 确认 `kDebugAlwaysFeedWatchdog = false` |

## 四、验收演示（照这个顺序做，`docs/00` 第 4 节）

1. 上电 → 2.5s 进 Working，舵轮不动
2. 跟随 + 轻推 → 车沿枪口前进
3. 保持前进、转云台 → 车头跟着转，方向不变
4. 分离 + 推杆 → 沿枪口平移，车头不转
5. 小陀螺 + 拨轮 → 原地自旋，推杆平移方向不变
6. 急停 → 全部立刻停
7. 关遥控器 → 0.2s 复位
8. 拔两板 CAN → 0.1s 两板都停
9. 重连调试器读 `g_reset_by_iwdg` → true（证明是看门狗复位）
10. （可选）`docs/08` 的 8 项故障注入

**一句话讲解**（被问到时）：
> 看门狗只在控制周期末尾喂，控制卡死就复位；非法 DBUS 整帧丢弃；未进 Working 一律归零。

## 五、三条底线

1. **电机架空再上电**，第一次落地用最低速。
2. **手不离急停**（右拨杆最下）。
3. 出问题先**断电**再查线，不要带电插拔电机线。
