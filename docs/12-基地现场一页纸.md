# 12 · 第一次调车：手把手版（含烧录）

> 给"从没调过车"的人看。每一段写清：**手怎么动、命令怎么敲、眼睛看什么**。
> 不需要懂原理，照着做。

# 第 0 步：烧录（到基地第一件事）

**烧录时不要接电机。** 烧完芯片会自动复位、程序立刻开始跑；此时电机没接，最安全。

## 0.1 认工具

| 东西 | 在哪 |
|---|---|
| OpenOCD（烧录软件） | `D:\ForDownload\stm32-env\openocd\bin\openocd.exe` |
| ST-Link（烧录器） | U 盘大小，一头 USB，一头 4 根线 |
| 板上的 SWD 插座 | 4 针，丝印写着 3V3 / SWDIO / SWCLK / GND |

## 0.2 接线（一次只接一块板）

```
ST-Link          板子 SWD 座
3V3    ────────  3V3
SWDIO  ────────  SWDIO
SWCLK  ────────  SWCLK
GND    ────────  GND
```

⚠️ **3V3 和 GND 接反可能烧板**。接线前把 ST-Link 外壳上的丝印和板上的丝印各看一遍，再插。

接好后**给这块板单独上电**（接电池、开开关）。

## 0.3 烧底盘板

```powershell
& "D:\ForDownload\stm32-env\openocd\bin\openocd.exe" -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program {D:/ForTest/steered_skeleton/steered_skeleton/Chassis/build/steered_chassis.elf} verify reset exit"
```

成功的样子：

```

shutdown command invoked
```

## 0.4 烧云台板

底盘板断电、拔线 → 接到云台板 → 云台板上电 → 换路径再跑：

```powershell
& "D:\ForDownload\stm32-env\openocd\bin\openocd.exe" -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program {D:/ForTest/steered_skeleton/steered_skeleton/Gimbal/build/steered_gimbal.elf} verify reset exit"
```

两块都 `Verified OK` → 断电、拔线、收好 ST-Link。

## 0.5 烧不进去对照

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `Error: open failed` / 找不到 ST-Link | 驱动没装 | 装 `D:\ForDownload\stm32-env\openocd\drivers\ST-Link` 里的驱动；换 USB 口 |
| `Error: init mode failed` | 板子没电 / 线接反 / 没接 GND | 确认板子灯亮；检查 4 根线；按一下复位键再跑 |
| 卡住不动 | 板子在复位/低功耗 | 按板上复位键再跑 |
| `couldn't open ... .elf` | 没编译或路径错 | `Test-Path <路径>` 确认文件存在 |

## 0.6 改了代码：编译 ≠ 烧录

**编译只动电脑上的文件，不碰板子。** 工程的 `POST_BUILD` 只把 `.elf` 转成 `.hex/.bin`，没有烧录命令。

```powershell
# ① 编译（按你改的是哪块选）
& "D:\ForDownload\stm32-env\cmake-4.4.3-windows-x86_64\bin\cmake.exe" --build "D:\ForTest\steered_skeleton\steered_skeleton\Chassis\build\audit"
& "D:\ForDownload\stm32-env\cmake-4.4.3-windows-x86_64\bin\cmake.exe" --build "D:\ForTest\steered_skeleton\steered_skeleton\Gimbal\build\audit"

# ② 烧录（和第 0.3 / 0.4 节完全一样）
& "D:\ForDownload\stm32-env\openocd\bin\openocd.exe" -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program {D:/ForTest/steered_skeleton/steered_skeleton/Chassis/build/steered_chassis.elf} verify reset exit"

# ③ 上电看现象  ④ 不对回 ①
```

| 你改的文件 | 编译/烧录哪块 |
|---|---|
| `Chassis/` 下面 | 只底盘 |
| `Gimbal/` 下面 | 只云台 |
| **`RobotComponents/` 下面（两板共用）** | **两块都要** |

产物固定：`Chassis\build\steered_chassis.elf`、`Gimbal\build\steered_gimbal.elf`。

## 0.7 如果换了电脑

上面命令里的路径是**这台电脑**的。换电脑先确认：

```powershell
Get-Command openocd            # 找不到就改路径
Test-Path "D:\ForDownload\stm32-env\openocd\bin\openocd.exe"
```

找不到 OpenOCD 的兜底：用另一台装好的电脑、或问组长要基地的烧录环境。
**编译也一样**：换了没有 ARM 工具链的电脑就编不了，可以在现在这台编好，把 `.elf` 拷过去只做烧录。

# 第 1 步：架车并固定

四块砖或两张凳子，四轮悬空。

**把车固定住**：轮子转起来车会在架子上"爬"，用扎带或手扶住。

# 第 2 步：认东西（不上电）

| 东西 | 长什么样 | 在哪 |
|---|---|---|
| 电池 | 方形，两根粗线 | 车底盘 |
| 底盘板 | 绿板，插很多线 | 车底盘中间 |
| 云台板 | 另一块绿板 | 云台上 |
| 驱动电机 | 带黑色小盒子（C620 电调） | 四个轮子旁 |
| 转向电机 | 圆柱形、高一点（GM6020） | 四个轮子旁 |
| 接收机 | 小盒子接一根细线 | 贴在车上 |

# 第 3 步：把 10 个电机**全部**接上

## 为什么不能"只接一个"

固件的安全设计是：**只要有一台电机离线，整车就停在 Dead、一动不动**。

- 底盘板要 **8 台**（4 驱动 + 4 转向）全在线；
- 云台板要 **2 台**（达妙）全在线；
- 两块板还要互相看见（双板 CAN 通、都上电）。

所以组长说的"一个一个来"，是指**一次只关注一个轮子**，不是"只接一个电机"。
只接一个轮组，你推杆它**一定不动**——不是坏了，是安全设计。

## 怎么接

| 线 | 接到哪 |
|---|---|
| 4 个驱动电机（C620）的 CAN | 底盘板 **CAN1** |
| 4 个转向电机（GM6020）的 CAN | 底盘板 **CAN2** |
| 2 个达妙电机的 CAN | 云台板 **CAN2** |
| 两块板之间的 CAN | 底盘板 **CAN1**（和驱动电机同一条总线） |
| 遥控器接收机 | **两块板**的 USART3（只接一块，另一块不进 Working） |
| 所有电机的电源 | 配电板（红黑别接反） |

接完检查：插紧、没短路、红黑对、没有线皮被夹破。

# 第 4 步：第一次上电

1. **先开遥控器**；
2. 再开车上电源；
3. **前 2 秒不要碰车**（IMU 在做零漂标定，动了要重来）；
4. 等 3 秒。

**你会看到**：板上的灯亮；接收机的灯通常从闪变常亮（型号不同可能不一样）；有的电机会有轻微自检声（没有也正常）。

**有没有冒烟、焦味、电机发烫？** 有 → 立刻断电。

## 没有调试器时，怎么知道进没进 Working

- 用手**轻轻拨一下云台**：有阻力、松手会回弹 = 已经使能（Working）；
  松松垮垮 = 还在 Dead。
- 推一下左摇杆：轮子开始转 = Working。

---

# 第 5 步：推杆，一次只盯一个轮子

左摇杆**慢慢推到 10%**，先盯**左前轮**：

1. 舵机先把轮子**转到朝前**（"吱"一声）；
2. 然后轮子**往前滚**。

记下来，再依次看左后、右后、右前：

| 看到 | 记成 |
|---|---|
| 轮子朝后滚 | 驱动反 |
| 轮子转到朝后 | 转向反 |
| 转正了但不滚 | 驱动不动 |
| 什么都不动 | 全不动 |

---

# 第 6 步：方向反了怎么改（改一个轮子）

1. 断电；
2. 打开 `Chassis/Instance/component/ins_motor.cpp`；
3. 找到 `kWheelDir`（驱动）或 `kSteerDir`（转向）那一行；
4. 把对应那一项的 `kDirFwd` 改成 `kDirRev`（或反过来）；
5. 编译底盘 → 烧底盘 → 重新上电 → 再看。

数组下标对应：`0=左前  1=左后  2=右后  3=右前`。

> 舵角"差一个固定角度"才需要改 `kSteerAngleOffset`，第一轮先不动。

---

# 第 7 步：落地，第一次真的跑

车放空地中间，周围 2 米没人。左摇杆推 **5%**。

车慢慢直着走。走歪先记下来。**手一直放在急停上**（右拨杆最下）。

---

# 第 8 步：云台

- 右摇杆上下 → 枪口抬高/低头；
- 右摇杆左右 → 云台左右转；
- **用手转整个车** → 枪口应该**不动**。

---

# 第 9 步：安全三件事（验收必考）

| 做什么 | 应该看到 |
|---|---|
| 右拨杆打到最下 | 所有轮子立刻停 |
| 关遥控器 | 约 0.2 秒后板子重启（灯闪一下） |
| 拔两板之间的 CAN 线 | 0.1 秒内车停 |

> 急停是**保持型**：拨杆停在最下时车一直停；要把右拨杆移回上面才会恢复。

# 附：现场常见坑

| 坑 | 表现 | 怎么办 |
|---|---|---|
| 电池没电 | 莫名其妙复位、轮子没劲 | 电压低就换电池，别用快没电的调车 |
| 电机 ID 不对 | 某台电机完全没反馈 | ID 是电调上设的，代码改不了；用大疆上位机确认 ID 与代码表一致 |
| 只烧了一块板 | 两板代码不一致，行为怪异 | 改共享代码后两块都要烧 |
| 接收机只接一块板 | 另一块板永远不进 Working | 两块的 USART3 都接 |
| 双板 CAN 没接 | 两块都停在 Dead | 接上底盘板 CAN1 |
| ST-Link 3V3/GND 反接 | 可能烧板 | 接前对两遍丝印 |

---

# 卡住了怎么办

1. **先打一下急停**（右拨杆最下），再移回去，等 2 秒——很多"车不动"是安全锁存；
2. 还不行，发我三句话：做到第几步 / 看到什么 / 哪个电机。
