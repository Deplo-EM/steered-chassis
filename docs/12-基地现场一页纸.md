# 12 · 第一次调车：手把手版（含烧录）

> 给"从没调过车"的人看。每一段都写清楚：**手怎么动、命令怎么敲、眼睛看什么**。
> 不需要懂原理，照着做。

---

# 第 0 步：烧录（到基地第一件事，30 分钟）

**没烧录，后面全是空谈。两块板各烧一次。**

## 0.1 认工具

| 东西 | 在哪 |
|---|---|
| OpenOCD（烧录软件） | `D:\ForDownload\stm32-env\openocd\bin\openocd.exe` |
| ST-Link（烧录器） | 一个 U 盘大小的东西，一头 USB，一头 4 根线 |
| 两块板 | 底盘板、云台板，板上都有一个 **4 针的 SWD 插座**（丝印写着 3V3 / SWDIO / SWCLK / GND） |

## 0.2 接线（一次只接一块板）

1. ST-Link 的 USB 头插电脑。
2. 4 根线接到**底盘板**的 SWD 插座：
   - `3V3` → `3V3`
   - `SWDIO` → `SWDIO`
   - `SWCLK` → `SWCLK`
   - `GND` → `GND`
3. **给底盘板上电**（接电池、开开关）。板子必须自己有电，ST-Link 供不动整板。

## 0.3 烧底盘板

打开 PowerShell，复制这一行回车：

```powershell
& "D:\ForDownload\stm32-env\openocd\bin\openocd.exe" -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program {D:/ForTest/steered_skeleton/steered_skeleton/Chassis/build/steered_chassis.elf} verify reset exit"
```

**看到这些就是成功**：

```
** Programming Started **
** Programming Finished **
** Verified OK **
** Resetting Target **
shutdown command invoked
```

最后一行应该是 `shutdown command invoked`，没有 `Error`。

## 0.4 烧云台板

1. 底盘板断电，拔掉 ST-Link 的 4 根线。
2. 同样 4 根线接到**云台板**的 SWD 插座。
3. 云台板**上电**。
4. 改一个词再跑：

```powershell
& "D:\ForDownload\stm32-env\openocd\bin\openocd.exe" -f interface/stlink.cfg -f target/stm32f4x.cfg -c "program {D:/ForTest/steered_skeleton/steered_skeleton/Gimbal/build/steered_gimbal.elf} verify reset exit"
```

两块都看到 `Verified OK`，烧录就完成了。断电，拔线。

## 0.5 烧录报错对照

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `Error: open failed` / `No ST-Link found` | ST-Link 驱动没装 | 装 `D:\ForDownload\stm32-env\openocd\drivers\ST-Link` 里的驱动；或换 USB 口 |
| `Error: init mode failed (unable to connect to the target)` | 板子没供电 / 4 根线接反 / 没接 GND | 先量板子有没有电；把 3V3 和 GND 对调试试；确认 SWDIO/SWCLK 没接反 |
| 命令能跑但一直卡住 | 板子处在复位或低功耗 | 按一下板上复位键再跑 |
| `couldn't open ... .elf` | 路径写错，或还没编译 | 确认文件存在：`Test-Path "D:\ForTest\steered_skeleton\steered_skeleton\Chassis\build\steered_chassis.elf"` |

## 0.6 改了代码要重新烧

改完一个数字后，**先编译，再烧**：

```powershell
# 编译底盘
& "D:\ForDownload\stm32-env\cmake-4.4.3-windows-x86_64\bin\cmake.exe" --build "D:\ForTest\steered_skeleton\steered_skeleton\Chassis\build\audit"

# 编译云台
& "D:\ForDownload\stm32-env\cmake-4.4.3-windows-x86_64\bin\cmake.exe" --build "D:\ForTest\steered_skeleton\steered_skeleton\Gimbal\build\audit"
```

编译产物固定在这里，路径不会变：

- 底盘：`Chassis\build\steered_chassis.elf`
- 云台：`Gimbal\build\steered_gimbal.elf`

编译成功的样子：最后一行是 `[N/N] Linking CXX executable ...`，没有 `error:`。

# 第 1 步：把车架起来

找四块砖或两张凳子，把车架上去，**四个轮子悬空**。

为什么：轮子一落地车就真的跑，第一次调试必须悬空。

---

# 第 2 步：认东西（不上电）

| 东西 | 长什么样 | 在哪 |
|---|---|---|
| 电池 | 方形，两根粗线 | 车底盘 |
| 底盘板 | 绿板，插很多线 | 车底盘中间 |
| 云台板 | 另一块绿板 | 云台上 |
| 遥控器 + 接收机 | 遥控器像手柄；接收机是小盒子，接一根细线 | 贴在车上 |
| ST-Link | U 盘大小 | 已用完，收好 |

---

# 第 3 步：只上电，看它活没活

**动作**：先开遥控器 → 再开车上电源。

**你会看到**：
- 板上的灯亮；
- 云台"滴"一声（电机自检）；
- 接收机的灯从"闪"变"常亮"。

**等 3 秒**，检查：冒烟？焦味？电机发烫？有 → **立刻断电**。

推遥控器轮子**不动**，是对的（还没进工作状态）。

---

# 第 4 步：只接一个轮组

找**左前轮**，两个电机：
- **转向电机**：圆柱形、高一点
- **驱动电机**：带黑色小盒子（C620）

接三根线：
1. 转向电机 CAN → 底盘板 **CAN2**
2. 驱动电机 CAN → 底盘板 **CAN1**
3. 两个电机电源 → 配电板（红黑别反）

接完检查一遍再上电。

---

# 第 5 步：推遥控器，看第一个轮子

左摇杆**慢慢推到 10%**。

**你会看到，按顺序**：
1. 舵机先把轮子**转到朝前**（"吱"一声）；
2. 然后轮子**往前滚**。

不对就记下来：

| 看到 | 记成 |
|---|---|
| 轮子朝后滚 | 驱动反 |
| 轮子转到朝后 | 转向反 |
| 转正了但不滚 | 驱动不动 |
| 什么都不动 | 全不动 |

---

# 第 6 步：四个轮子都接上

另外三个同样接（转向→CAN2，驱动→CAN1，电源→配电板）。

- 推前后：四个都朝前
- 推左右：四个一起转到侧面
- 转拨轮：四个一起左右转

---

# 第 7 步：落地，第一次真的跑

车放空地中间，周围 2 米没人。左摇杆推 **5%**。

车慢慢直着走。走歪先记下来。**手一直放在急停上**。

---

# 第 8 步：云台

- 右摇杆上下 → 枪口抬高/低头
- 右摇杆左右 → 云台左右转
- **用手转整个车** → 枪口应该**不动**

---

# 第 9 步：安全三件事（验收必考）

| 做什么 | 应该看到 |
|---|---|
| 右拨杆打到最下 | 所有轮子立刻停 |
| 关遥控器 | 约 0.2 秒后板子重启（灯闪一下） |
| 拔两板之间的 CAN 线 | 0.1 秒内车停 |

---

# 卡住了怎么办

1. **先打一下急停**（右拨杆最下），再松开，等 2 秒——很多"车不动"是安全锁存。
2. 还不行，发我三句话：做到第几步 / 看到什么 / 哪个电机。
