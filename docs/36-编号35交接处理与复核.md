# 编号 35 交接处理与复核

2026-11-16 · 基于 `c73c2b4` 与当前工作区。已完成源码修复、主机回归和离线构建。**整车保持断电。** 上次 Yaw 自转无法靠遥控急停停止，必须先核实独立断动力和驱动失联停机；这些构建没有烧录到车上。

## 已复核的现象与改动

| 交接现象 | 复核结果与修复 |
|---|---|
| B01 显示 `steer_feedback[0]=26.65 rad` | 对过 B01 ELF：`InitMotors` 的舵角配置为单圈，`GM6020::decode` 对带偏移的角度调用归一化；两种配置用实际驱动对每个舵轮遍历八圈编码器读数，也未出现越界。现场读数仍需证据解释：限速目标和最终目标是连续角，能超过 ±π；实测舵角超出则无效。新版拒绝这种反馈，立即停全底盘并锁定恢复资格，停机快照记录原值和轮位。 |
| 降舵角增益后仍翻号 | 复现了一条确定的代码路径：实测舵角在 0°，上一目标 +92°、下一目标 −92° 时，旧版从上一目标取最短弧，经舵机背后跨过 ±π，周期误差会反号。新版在实测角所在的分支上限速；短暂低于 0.02 m/s 时保留等效解的历史，恢复时不因跨零速门限重选。仍未确定这就是 B01 全部振荡的原因。 |
| 轮胎快速跳动，回中后偶发推轮 | 旧版误差在 0.349 与 0.351 rad 之间跳变，主机可复现整组轮速开关反复通断；目标零速时旧积分还能请求推进电流。新版仍在 0.35 rad 超限时当拍关断，降到 0.30 rad 以内才重新许可；零轮速目标清积分和电流请求。整组对齐及堵转锁存继续生效，等待超时不会放行其他轮。 |
| 正常操作进 `Dead` | 复现并修复了下条 Yaw 溢出路径；底盘 B01 当时的 `last_dead_` 没有记录，不能用此前的堵转或 IMU 快照补作结论。此前 `imu-sample-fix` 确认过一次 `kAccLow`，详见 [30](30-BMI088采样修复与现场回归.md)；这次未降低判废、堵转或急停保护。 |
| B14 大角差下可能进 `Dead` | Yaw 的 3.5 N·m PID 限幅之后又加前馈。例如同向 2 rad/s 时合计可到 4.1 N·m，达妙的 `setInput` 报越界，上层把正常饱和判成故障。新版对合计力矩按电机配置与 PID 限幅的较小值限幅，并以合计输出做抗积分饱和；停止时清掉前馈。此缺陷可导致停机，不能解释两次急停失效。 |
| 急停后的一次失能确认可能过期 | 模拟急停时已确认两轴失能、随后单轴重新报告使能，旧版会用先前确认重新开放使能或正常帧。新版撤销旧确认，继续发失能，只有在在线时限内再次确认两轴都正常失能才允许恢复。 |
| 全量主机测试停在控制组 | 当前工作区已没有 `ins_motor_safety.hpp` 引用。实际基线是电压配置也被改成电流档的低 Kp，旧电流测试还使用调整前的预期。恢复备用电压版 `10000 / 2000 / 150`，保留 B01 电流版 `6000 / 400 / 120`，分别用真实驱动检查角度和编码，并把电流版加入状态机集成测试。 |

未修改接线、设备 ID、CubeMX 生成区、电机库或电机内部配置。底盘实测电流配置仍为 CAN1 舵帧 `0x1FE` 和 ±1.2 A；云台 B14 的 Yaw/Pitch 增益、前馈系数和软限位保持原值。

## 怎样继续判断

如果已经有保存的截图或采样，用当时同一份 ELF 解读数据。不要为补数值重新上电复现。条件满足后需要定位时，先保存 `s_robot.last_dead_` 的 `tick_ms`、`causes` 和子项，再看实时曲线。

| 看到什么 | 意味着什么 |
|---|---|
| `causes & 1` 非零 | 舵向停滞。对照 `s_chassis.last_steer_stall_` 和同序号的 `g_steer_stall_tx`；CAN 发送完成不能证明电机消费帧或实际出力。 |
| `causes & 8` 非零 | IMU 判废。核对 `last_imu_dead_.imu.reason`、样本和时间；不能按舵 PID 问题处理。 |
| `causes & 16` 非零 | 电机反馈不满足条件。若 `last_dead_.steer_angle.mask` 非零，在 `measured_rad` 读对应轮的原值；bit0 到 bit3 依次是左前、左后、右后、右前。mask 为 0 时优先区分电机掉线、健康或速度反馈异常。 |
| 仍 `Working`，`drive_ready=0` 且 `align_blocked_mask` 非零 | 轮速正在等待舵向，不是急停。对照 `steer_error` 和最终目标；若只有 `steer_feedback` 在 ±π 两边折返、误差连续，那是角度表示。无轮速需求时 `drive_ready` 也为 0。 |
| 云台的 `yaw_output` 非零 | 新版这个字段是限幅后的合计力矩请求；`yaw_ff_torque` 是限幅前的前馈分量。二者都不是电机实测扭矩。停机后两项应为 0；仍需用驱动状态和实际停机证据确认。 |

老的 Ozone 工程文件仍指向各自用于对照的旧 ELF。新的调试结构体和停机记录有变动；桩测试显示输出归零，和芯片/执行器实际停机是两份证据。恢复条件以 [Yaw 停机复核](35-Yaw异常转动与急停失效.md) 为准。
