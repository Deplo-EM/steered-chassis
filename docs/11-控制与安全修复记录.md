## 4. 未验证与保留边界

1. **台架T1–T8未执行，实车参数整定和机械行程未验证，不能判定整车安全验收完成。**
2. BMI088驱动未上报SPI读取状态；物理上合理的旧值冻结仍可能通过数值检查。T3用于复现此局限。
3. CAN提交成功只代表入邮箱；总线故障时零命令也可能送不到，队列中的旧命令和电机自身超时/卸力须实测。需独立驱动电源急停。
4. 主机测试不证明1ms最坏耗时、中断抢占时的共享多字段一致性或真实电机执行时序。当前接收中断仍更新共享对象，尚未引入统一的输入快照机制。
5. 8位序号检查不提供身份认证，无法排除完整循环的历史帧重放。
6. 独立复核发现的“云台单独重启绕过恢复”和“在线调小积分限幅回滚越界”均已补测试修复；独立复核本身未运行硬件。

上电与任何Dead恢复都先保持有效遥控急停，检查状态、摇杆回中和活动区域，再解除。具体操作按 `docs/06` 和 `docs/08` 记录。
