## 三、与 38/39 号文档的一致性

- 首跑版**不含**摩擦前馈、排除轮、逐轮放行、禁翻转、禁堵转（见 40 号）；
- 摩擦补偿按 39 号结论关闭；`dsh-friction-B01` 与 `dsh-friction-nostall-B02` 退出试车候选，仅留作离线对照；
- 轮位 ID 数组 `{3,4,1,2}` 与零点数组（按物理轮位）保持 38 号表；实物 ID/方向/零点仍需按 38 号清单逐轮核对；
- 38 号列出的起步门槛与 600 ms 对齐超时锁存均已实现并由主机测试覆盖。对齐超时仍需在机械干涉处理后的台架验证；首跑结论不延伸到普通考核构建。
