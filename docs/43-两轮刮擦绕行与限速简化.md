# 两轮刮擦绕行与限速简化

2026-11-17。R2 删除小陀螺独立的 0.60 m/s 平移上限和 2.0 m/s² 斜坡，恢复三种模式共用的平移指令和斜坡。原有轮速限制按每个轮组的实际速度矢量检查；只当某轮将超限时才缩减平移，优先保留可实现的旋转。例：`vx=2 m/s`、`w=5 rad/s` 时，四轮中最快的约 2.96 m/s，低于 3 m/s，R2 保留平移 2 m/s。急停、看门狗、堵转、对齐和原有电流限值仍在。

## 两轮各走各的可达路径

同一条滚动速度可以用舵角 θ 和轮速 v 实现，也可以用 θ+π 和 −v 实现。参见 [FIRST 官方舵轮等效解说明](https://docs.wpilib.org/en/stable/docs/software/kinematics-and-odometry/swerve-drive-kinematics.html#module-angle-optimization)。R2 从每个轮的实测舵角出发，检查到两个目标的整段圆弧，包括起点和终点。两支都通时照常按转角和回差选支；一支经过刮擦区时选另一支，两轮独立决定，四轮仍共同实现同一个运动。区间跨 −π/+π 也可表达。

任一轮两支都不通或反馈已经落在禁入区，底盘四舵和四轮归零，撤销待发电机旧帧；正常新指令可以重新规划。算法不向障碍尝试脉冲，也不让对齐的其他轮拖着走。

## 验收时什么情况才算合格

无路时归零是兜底，频繁触发不能算三模式通过。只要**每个受影响轮位只有一段连续的禁入区、含裕量的总宽度小于 180°，实测起点又在区外**，剩余可转角度便超过 180°。把这段畅通角度摊成一条线，任一滚动方向的两支等效舵角相隔 180°。从起点在畅通范围内能找出一个连续的 180° 区间，其中必有一个等效目标；从起点到它不用跨禁入区。两只轮分别满足这个条件时，可以各自选支来完成同一运动。

这是舵角几何的覆盖条件。已选到路径时，切换等效支仍可能等待实物对齐，不能由主机测试推断跟踪时间或不停顿。若畅通角度不足、起点在区内或刮擦随载荷变化，先核查机械间隙；不要通过跳过对齐条件来声称合格。

补充回归：电压、电流、考核电流三种配置各覆盖 105,840 条模拟请求，从两只舵轮不同的区外起点扫 360 个平移方向，并叠加两种旋转指令。三组均未出现无路。另一个故意制造无路的用例采用约 229° 宽的模拟禁入区，它是边界用例，未用于实车配置。

**实车区间未填写。** 先隔离动力、稳固支撑车体，再确认两个轮各自在哪个物理轮位、哪些舵角确实会碰。划定区间时包含实际跟踪误差、装配和悬挂行程造成的偏差；无实际数据时不填猜测数值。带负载才可能出现的接触要另查机械间隙。若轮胎在整个滚动行程都刮，或硬卡导致没有可用圆弧，优先检查挡件、松动和线束走向，恢复机械间隙后再试。参见 [HSE 动力隔离指导](https://www.hse.gov.uk/work-equipment-machinery/maintenance.htm)。

填在 [ins_chassis_iksolver.cpp](../Chassis/Instance/component/ins_chassis_iksolver.cpp) 的 `kGeometry.steer_keepout`：顺序左前、左后、右后、右前；每个条目是 `{中心角, 半宽}`（rad，半宽含裕量）。半宽 0 表示这只轮未启用绕行；跨 ±π 时先把两个边界放在同一个连续角区间里求中心和半宽，再把中心归一到 ±π 内。传感器符号按轮位核验，不能用电机 ID 的序号代替物理位置。
