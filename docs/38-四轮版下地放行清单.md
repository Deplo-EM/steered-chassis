# 四轮版下地放行清单

**2026-11-16：目前不可带动力下地。** [37 号交接](37-转Codex-下地前确认.md)记录了右后舵轮有固定卡点，也没有独立断动力、遥控急停和驱动失联停机均通过的记录。只有约 2 m 的空位、人在旁边可扶车，不能作为放行条件。补全版考核说明第 11 页要求上电调试时车轮离地，整机测试前先验证单电机方向和舵角零点。先做断电检查；后续调试仍在固定架空台架完成。

## 放行检查，按顺序完成

- [ ] **先消除右后干涉。** 动力隔离且车辆由稳固支架固定后，检查支架、线束和车体是否干涉，确认正常工作范围内无卡点；若疑似接地受载才会复现，做受控机械检查。不要强推舵轮经过卡点，不用排除轮、逐轮放行或调大电流来绕过。当前 300 ms 对齐超时只记录，不能保证舵输出归零；现有主机回归明确覆盖了约 45° 卡住 1 秒仍不报堵转。
- [ ] **独立断动力和受控台架就绪。** 人不用接近车或伸进运动范围，就能用已验证的独立手段切断动力。先在动力隔离的条件下核对同一对固件的软件停机路径，独立断动力和实际驱动停止出力要在有防护的台架验证。按 [35-Yaw 停机复核](35-Yaw异常转动与急停失效.md)核对遥控急停、遥控掉线、驱动失联停机，确认未授权时两板都不出力。不能靠手扶车、调试器暂停或看门狗复位替代断动力。
- [ ] **逐轮确认实际 ID、方向和零点。** 分开记录四个驱动电机和四个舵电机，尤其确认 ID1/ID4；轮胎朝车头时，按同一物理基准核对舵角接近零。指令、反馈和机械动作必须对应同一轮；驱动方向按轮实际朝向判断，允许等效解里的舵角换向与轮速同时反向。几何用上表；没有发现实测差异，无须为重绑改半径或轮距。
- [ ] **确认解除急停不会立刻走车。** 软件审查发现当前只要求有效急停确认，没有等待摇杆和拨轮稳定回中，也没有单独的起步授权；杆量未回中或小陀螺档仍有自动起动条件。应先补并验证中位及显式起步门槛；人记得回中只是操作约束，不能替代这个检查。
- [ ] **架空核实换向与停机。** 保留翻转。最终等效角换支接近 180°，可以是显示上的目标变化；限速目标、实测舵角和轮电流不能有异常跳动、持续振荡或持续顶住。37 号新 IMU 记录只有原因位 `8`，不能认定与旧 `kAccLow` 同因；若再次停机，保存同一事件的时间戳和 `last_imu_dead_.imu.reason`，暂停推进。
- [ ] **最后单独评估负载和场地。** 轮速环 `0.50 / 0.30` 的空载结果尚未证明带地面负载稳定。所有上项通过后，才另行安排正式低速试跑：使用隔离的场地和经验证的低速上限，只从分离档直线起步和停车开始，确认停车距离，再讨论跟随和小陀螺。不要把落地当作排查刮蹭、急停或 PID 振荡的手段。

## 两处可直接追溯的代码问题

1. [底盘授权](../Chassis/RobotModules/component/robot.cpp#L265)检测到急停档即保存授权；[底盘测试](../tests/test_robot_safety.cpp#L492)有左杆非中位、确认急停再放开后出力的用例。应新增反例并让中位确认、起步许可独立于解除急停。
2. [对齐和堵转](../Chassis/RobotModules/component/chassis.cpp#L173)里对齐超时只标记；[checkSteerProgress](../Chassis/RobotModules/component/chassis.cpp#L285)在出力不足阈值时清掉计时。小角差卡死仍可能持续输出舵电流，[现有测试](../tests/test_control.cpp#L301)可复核。先修机械干涉，再评估独立的“不进展且长时间出力”保护。

补全版写 DM-J4310，后来的修正拓扑标 DMJ620，代码仍使用 DM-J4310 的协议标度。[已有记录](22-舵轮回归修复与台架核对.md)没有给出足够证据判定实际型号或量程；在做两轴停机确认时一并追溯现有铭牌和受控只读记录，不改电机内部设置。

现阶段能做的是：动力隔离后检查右后干涉、按上表核对可见标识、保存已有的实车记录，电脑上检查版本及保护。普通控制命令和电源隔离是两种措施。参见 [HSE 安全维护指导](https://www.hse.gov.uk/work-equipment-machinery/maintenance.htm)。
