# 舵向与云台收敛调整 Implementation Plan

**目标**：保留已通过三种模式的两份 ELF，分别提供底盘、云台候选版，以固定目标的过冲和稳定时间做 A/B 对比。

**设计**：世界系 Yaw 和电流版舵向使用同坐标系的实测角速度做微分阻尼；Pitch 保留关节角和行程限制，用关节转速做阻尼并小幅增加位置比例。Yaw 和舵向减小积分影响。基础速度、模式、通信、零点、输出限幅和急停不改。架空与落地分别验收。

1. `tests/test_control.cpp` 先锁定电流报文中不再叠加目标斜坡微分、实测转速的作用方向、静止卡舵仍停机。通用 `pid.hpp` 提供接收实测速度的入口，保留原误差差分和限幅逻辑。`chassis.cpp` 只在电流版使用新入口。
2. `tests/test_robot_safety.cpp` 用真实云台模块与实际 PID 初始值，核对固定姿态下的目标跳变、Pitch 小误差响应及外向力矩限制；Robot 集成核对世界 Yaw 阻尼、跨 ±π 和急停。`gimbal.cpp` 使用世界 Yaw 转速和 Pitch 关节转速；`robot.cpp` 计算世界 Yaw 转速。
3. 用 CMake/Ninja 编译到新路径，提供单板 Ozone 工程，校验工作版文件 SHA-256 不变。完整运行主机回归；机械效果只由实车 A/B 确认。
