# 修复陀螺仪就绪信号漏采

现场证据：云台合法DBUS帧持续增长，板间在线；云台在Dead/Resurrection间变化，IMU已标定而`stale_gyro_`持续增长，SPI、设备时钟和样本数值拒绝计数未见对应增长。Bosch BMI088手册 §4.7.2 的陀螺仪DRDY仅维持280–400µs，1ms定时轮询会连续漏过。目标是修复采样证据，不放宽20ms失效判定和出力条件。

- [x] 在真实BMI088/Imu主机测试中模型化持续出样但短脉冲总被错过，记录改前失败。
- [x] 双板驱动以陀螺仪FIFO帧数确认新数据，按有界帧数突发读取，空FIFO不更新时间，积压/溢出清队列并拒绝当次样本。
- [x] 对批次按真实样本数累计标定与积分；用已验证的配置采样率；不改变控制和CAN时序。
- [x] 验证脉冲漏采、静止值相同、断流、传输错误和批次边界，再完整回归并构建两板；实板留待烧录验证。

完成：两板构建通过，全套主机回归1335项、0失败。独立复审提出的软复位时序、采样率和温度错误保护均已测试修正。实板待验。
