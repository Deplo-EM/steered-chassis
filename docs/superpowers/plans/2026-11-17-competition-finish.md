# 三模式收尾计划（v22 / B22 之后）

1. 从当前源码和最新构建配置复核停机、舵向和小陀螺路径。保留已有固件、团队映射、本次不触碰 CubeMX 和设备配置。
2. 主机复现 Pitch 合计力矩溢出、低模长加速度瞬态锁死、明显歪舵提前驱动，以及低转速小陀螺平移不给旋转留余量。
3. 按执行器实际力矩限值控制 Pitch；两板共用当前安全行程。只在已有工作授权时短暂续用最近合格的 IMU 状态，随后仍执行原有撤权。驱动按四舵对齐共同放行；提高正常电流版的舵角轨迹速度，不用卡点脉冲。
4. 旋转优先分配轮速，小陀螺合推限制平移速度/加速度，同步保留分离、跟随坐标语义。记录轮速指令推算偏航与陀螺读数，便于继续区分载荷与机械问题。
5. 运行主机全套测试，分别构建新的配对候选并核对标签和选项。写台架验收对照；不宣称未实测的响应时间、转速和轨迹。
